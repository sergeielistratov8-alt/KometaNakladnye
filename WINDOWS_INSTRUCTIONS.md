Инструкция: собрать кликабельное Windows-приложение (.exe) и ярлык на Рабочем столе

1) Подготовка
   - Откройте PowerShell с правами пользователя (Run as Administrator не обязателен, но может понадобиться при установке в систему).
   - Перейдите в папку проекта, например:

```powershell
cd "C:\Users\<you>\Desktop\KometaNakladnye"
```

2) Собрать exe автоматом
   - Запустите скрипт:

```powershell
.\BUILD_WINDOWS.ps1
```

   - Либо через .bat:

```cmd
build_windows.bat
```

3) Что делает скрипт
   - Создаёт виртуальное окружение `venv` (если нужно)
   - Устанавливает зависимости из `requirements.txt` (PySide6 устанавливается через pip; если возникают ошибки — используйте системный/дистрибутивный Qt)
   - Если `python` не найден, скрипт попытается использовать `py -3`
   - Устанавливает `pyinstaller`
   - Сборка `main.py` в папку `dist\KometaNakladnye\` с exe и всеми зависимостями (режим onefolder для надёжности Qt)
   - Создаёт ярлык на Рабочем столе `KometaNakladnye.lnk`

4) Проблемы и отладка
   - Режим сборки: `onedir` (onefolder) — гарантирует, что все зависимости (PySide6/Qt, pandas, openpyxl) будут включены и доступны для exe
   - Папка `dist\KometaNakladnye\` содержит все необходимые библиотеки. НЕ удаляйте и не перемещайте эту папку, иначе приложение не запустится
   - Для просмотра логов сборки запустите PowerShell и выполните команды по шагам: создание venv, установка пакетов, запуск `pyinstaller`
   - Если приложение не запускается, проверьте, есть ли в `dist\KometaNakladnye\` файлы библиотек (PySide6, pandas и т.д.)

5) Запуск
   - Двойной клик по `KometaNakladnye.lnk` на Рабочем столе запустит приложение.
   - Приложение автоматически обнаружит, что оно запущено через PyInstaller, и пропустит проверку зависимостей (все библиотеки в `_internal` уже подключены)

6) Уточнения
   - Если вы используете специфичное виртуальное окружение, активируйте его перед сборкой.
   - Скрипт не перезаписывает `requirements.txt`.
