# 🌟 Комета - Накладные

Мощная утилита для очистки Excel-таблиц от пустых строк и столбцов с графическим интерфейсом на Qt.

## 📋 Возможности

✅ **Удаление пустых строк и столбцов** из Excel-таблиц
✅ **Drag-and-Drop** - перетащите файлы прямо в окно
✅ **Двухстолбцовый интерфейс** - входные и готовые файлы  
✅ **Запоминание папок** - последний выбор источника и назначения сохраняется
✅ **Кроссплатформенность** - работает на Windows, macOS и Linux
✅ **Автоматическая папка готовых файлов** - создается в той же директории со скриптом
✅ **Поддержка форматов** - .xlsx, .xls, .csv

## 🚀 Установка

### Требования
- Python 3.8+
- pip

### Шаги установки

1. **Клонируйте или скачайте проект**
```bash
cd /path/to/KometaNakladnye
```

2. **Создайте виртуальное окружение** (рекомендуется)
```bash
# macOS/Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

3. **Установите зависимости**
```bash
pip install -r requirements.txt
```

## 💻 Использование

### Запуск программы
```bash
python main.py
```

### Сборка Windows-приложения
```powershell
.\build_windows.bat
```
или
```powershell
.\BUILD_WINDOWS.ps1
```

Скрипт создаёт виртуальное окружение `venv`, устанавливает зависимости, собирает `main.py` в папку `dist\KometaNakladnye\` с exe и всеми зависимостями и создаёт ярлык на рабочем столе.

Если `python` не найден в PATH, `BUILD_WINDOWS.ps1` попытается использовать `py -3`.

### Как использовать

1. **Выберите папку источника** - папка с исходными Excel-файлами
2. **Выберите папку назначения** - куда сохранять готовые файлы (по умолчанию папка `ready`)
3. **Добавьте файлы** двумя способами:
   - Нажмите кнопку "➕ Добавить файлы"
   - Или перетащите файлы прямо в левую колонку
4. **Нажмите "🚀 Начать обработку"**
5. Файлы переместятся в папку назначения автоматически

## 📁 Структура папок

```
KometaNakladnye/
├── main.py                 # Основная программа
├── requirements.txt        # Зависимости
├── README.md              # Этот файл
├── .config.json           # Конфигурация (создается автоматически)
└── ready/                 # Папка с готовыми файлами (создается автоматически)
```

## 🎨 Интерфейс

### Левая колонка (входные файлы)
- Список файлов для обработки
- Кнопка добавления файлов
- Кнопка удаления выбранных файлов

### Правая колонка (готовые файлы)
- Список обработанных файлов
- Кнопка очистки списка

### Функции
- **Выбор папки источника** - откуда брать файлы
- **Выбор папки назначения** - куда сохранять готовые файлы
- **Прогресс-бар** - показывает ход обработки

## ⚙️ Особенности

### Кроссплатформенность
Все пути используют `pathlib.Path` и `os.path` для полной совместимости с Windows, macOS и Linux.

### Работа с PyInstaller
При запуске скомпилированного exe-файла (Windows PyInstaller) приложение автоматически обнаруживает этот факт через `sys.frozen` и пропускает проверку зависимостей (все необходимые библиотеки уже включены в папку `_internal`).

### Запоминание папок
Конфигурация сохраняется в файле `.config.json`:
```json
{
  "source_folder": "/path/to/source",
  "dest_folder": "/path/to/destination"
}
```

### Папка готовых файлов
По умолчанию создается папка `ready` в той же директории, где находится скрипт:
```
script_directory/ready/
```

## 🐛 Возможные проблемы

### Qt (PySide6/PyQt5) не устанавливается на macOS
```bash
# Попробуйте установить PySide6 в активном виртуальном окружении
pip install PySide6
```

### Ошибка "Permission denied" на macOS
```bash
chmod +x main.py
python main.py
```

## 💡 Советы

1. **Используйте виртуальное окружение** - это изолирует зависимости вашего проекта
2. **Сохраняйте резервные копии** - программа перемещает файлы, не копирует их
3. **Для больших файлов** - обработка может занять некоторое время, прогресс-бар покажет ход
4. **Выбирайте разные папки** - для источника и назначения избежите перезаписи файлов
