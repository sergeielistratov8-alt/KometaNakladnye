Инструкция: сделать приложение (.app) на macOS, запускающее `main.py` двойным кликом

1) Проверьте, что проект находится в удобной папке (например, на Рабочем столе). В нашем примере проект корнем: `/Users/<ваш_пользователь>/Desktop/KometaNakladnye`.

2) Настройте интерпретатор (если нужно).
   - По умолчанию `run_main.sh` использует `python3` из PATH (`/usr/bin/env python3`).
   - Если вы используете виртуальное окружение, замените строку `PYTHON_EXEC` в `run_main.sh` на абсолютный путь к python внутри venv, например:

```
PYTHON_EXEC="/Users/you/.virtualenvs/venv/bin/python"
```

3) Соберите .app автоматически (рекомендуется):
   - Откройте Терминал и выполните из папки проекта:

```bash
cd /Users/<ваш_пользователь>/Desktop/KometaNakladnye
bash build_app.sh
```

   - Скрипт создаст `KometaNakladnye.app` на вашем Рабочем столе.

4) Что делает полученный .app:
   - При двойном клике он выполнит `run_main.sh` в фоне (через `do shell script`), который запустит `main.py`.
   - Терминал не будет открываться. GUI от PyQt запустится нормально.

5) Тонкости и устранение проблем:
   - Если приложение не запускается, убедитесь, что у пользователя есть права на выполнение: `chmod +x run_main.sh`.
   - Если используется Homebrew Python или venv, укажите абсолютный путь до интерпретатора в `run_main.sh`.
   - Если macOS спрашивает разрешения (Gatekeeper), в Finder правой кнопкой по `KometaNakladnye.app` -> Открыть -> Подтвердить.

6) Альтернативный ручной способ (Automator):
   - Откройте Automator -> New Document -> Application.
   - Добавьте действие "Run Shell Script".
   - Вставьте содержимое `run_main.sh` (без shebang) или вызов `/bin/bash /path/to/run_main.sh`.
   - Сохраните приложение на Рабочем столе.

7) Отладка:
   - Временно закомментируйте перенаправление в `run_main.sh` (`>/dev/null 2>&1`) чтобы видеть вывод в файле или в терминале:

```bash
nohup $PYTHON_EXEC main.py &
```

   - Логи можно писать в файл:

```bash
nohup $PYTHON_EXEC main.py > /tmp/kometa.log 2>&1 &
```


Если хотите — могу автоматически запустить `bash build_app.sh` и создать `.app` на вашем Рабочем столе прямо сейчас.
